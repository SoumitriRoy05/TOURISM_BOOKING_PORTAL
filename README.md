# 🇮🇳 BharatYatra - Tourism Booking Portal

> A modern full-stack tourism and travel booking platform designed to simplify destination discovery, hotel and flight exploration, and personalized trip planning.

---

## 📌 Overview

**BharatYatra** is a full-stack tourism booking portal that provides users with a unified platform to explore destinations, search for hotels and flights, and plan personalized trips.

The platform combines a modern React frontend with a Node.js/Express backend and provides authentication, REST APIs, search functionality, and an AI-powered trip planning experience.

---

## ✨ Features

- 🏠 Modern and responsive landing page
- 🗺️ Explore popular destinations
- 🏨 Hotel exploration and booking workflow
- ✈️ Flight search and exploration
- 🤖 AI-powered Trip Planner
- 🔐 User registration and login
- 🛡️ Authentication and protected routes
- 🔎 Travel search functionality
- 📱 Responsive user interface
- ⚡ Fast frontend powered by Vite
- 🔗 REST API based backend architecture
- 📊 Structured database models
- 🎨 Modern dark-themed travel UI
